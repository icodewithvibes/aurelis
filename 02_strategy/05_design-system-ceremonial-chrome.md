# Design System — "Ceremonial Chrome"

The identity: **cobalt night · reflective chrome/silver · meadow & wildflower · film grain + soft bloom · restrained prismatic light.** Quiet sacred resolve — equipped to execute. Luxury editorial wellness, **not** a game HUD, **not** military.

**Golden rule:** prismatic is an *accent used on < 5% of any screen* — reserved for focus, success, and crest moments. Chrome and cobalt do the heavy lifting; nature and grain keep it human.

> IP hygiene: all values below are **original AURELIS tokens**. Do **not** copy the reference `.liquid-glass` CSS, the Velorah/Asme HSL sets, or Instrument Serif. Our "forged-glass" values are deliberately distinct.

## 2. Typography (all SIL OFL — self-hosted, no IP risk, NOT Instrument Serif)
- **Display / manifesto:** **Fraunces** (variable, editorial serif, high contrast, optical sizing). For hero lines, section headers, ceremonial copy. Use italic sparingly for muted/emphasis words.
- **UI / body:** **Inter** (or Geist) — clean neutral sans for all interface text and data labels.
- **Numerals / timers / weights:** **IBM Plex Mono** (or Geist Mono) — tabular, so logged numbers and the rest timer don't jitter.

```css
--font-display: 'Fraunces', Georgia, serif;
--font-ui:      'Inter', system-ui, sans-serif;
--font-mono:    'IBM Plex Mono', ui-monospace, monospace;
```
Scale (mobile-first, rem): display 2.25 / 1.75 · h1 1.5 · h2 1.25 · body 1.0 · small 0.875 · mono-data 1.125. Tight tracking on display (`-0.02em`), normal on UI.

## 3. Materials & texture
- **Forged-glass panels:** `background: var(--aur-glass-bg); backdrop-filter: blur(var(--aur-glass-blur));` + a 1px gradient border via the mask technique using `--aur-glass-border`, + `box-shadow: var(--aur-glass-inset)`. **Do not animate `backdrop-filter`** (iPhone cost) — fade/scale the element instead.
- **Chrome dividers:** 1px hairline with a subtle silver gradient; used to separate sections like engraved lines.
- **Grain:** one pre-baked tiling PNG (monochrome noise) as a fixed overlay at `opacity: 0.04–0.06`, `mix-blend-mode: overlay`. Static, GPU-cheap. No canvas/JS grain.
- **Bloom:** pre-rendered soft radial glow PNG/gradient behind hero and completion states. Never a live filter loop.
- **Imagery:** meadow/wildflower/chrome stills generated by Fable/Higgsfield (original, per doc 06 asset briefs). Always behind cobalt scrim for text legibility.

## 4. Motion tokens (see product doc §Motion for per-surface behavior)
```css
--ease-ceremonial: cubic-bezier(0.16, 1, 0.30, 1);   /* slow settle */
--ease-standard:   cubic-bezier(0.4, 0, 0.2, 1);
--dur-fast: 150ms; --dur-base: 220ms; --dur-slow: 480ms; --dur-cinematic: 900ms;
```
- App UI: `--dur-fast`/`--dur-base`, transform+opacity only.
- Ceremony (session complete, crest level-up): `--dur-slow`/`--dur-cinematic`, one restrained prismatic sweep, pre-baked bloom.
- **Reduced motion:** all translate/scale removed; keep instant opacity or none; countdowns show numerically. Honor `prefers-reduced-motion` + the in-app `reducedMotion` setting.
- **Rest timer:** SVG ring driven by CSS `@keyframes` on `stroke-dashoffset` / a CSS transition, **not** per-frame JS. Calm pulse at 10s via a bounded CSS animation.

## 5. Chrome Crest — streak emblem system (NO swords, NO fire)
An abstract **crest/shield** mark that gains **botanical + cobalt + prismatic** detail as consistency grows. Calm, premium, ceremonial. Build as **layered SVG** (so levels are code-controlled + crisp at any size); optional generated texture overlays from Fable/Higgsfield for hero-size renders.

### Level progression (7 states)
| Level | Streak | Emblem state | What's added |
|---|---|---|---|
| Unmarked | 0 | Faint engraved shield outline, steel-400, low opacity | baseline silhouette only |
| First Mark | 1–2 | Single clean silver notch/etch appears | one engraved line |
| Polished Mark | 3–6 | Shield buffed to bright chrome, subtle inset highlight | reflectivity/shine |
| Silver Crest | 7–13 | Full defined silver crest form, crisp bevel | complete shield form |
| Cobalt Crest | 14–29 | Cobalt enamel inlay fills interior facets | cobalt color inlay |
| Prismatic Crest | 30–59 | Thin restrained spectrum refraction along the edges | prismatic edge light |
| Ascendant Crest | 60+ | Botanical wildflower filigree wreathing the crest + soft prismatic bloom | nature filigree + bloom |

### Rules
- Growth is **additive and subtle** — each level layers onto the previous silhouette; the shape stays recognizable throughout.
- Botanical detail = small original wildflower/leaf filigree (echoes the meadow world), never literal weapons.
- Prismatic only appears from level 6+ and stays a thin edge accent, never a full rainbow fill.
- **Completion moment (every qualifying session, LOCKED):** brief **450–650ms** sequence — clean silver edge-light on the crest → one botanical/cobalt detail resolves → one restrained prismatic glint passes across. Plays **only after** the proof is persisted to IndexedDB. iPhone-safe (transform/opacity + pre-baked glint gradient). **No** fire/swords/XP/coins/particles/confetti. Reduced-motion → static crest + result line ("Proof recorded — 1 session kept."), no animation.
- **Level-up transition** (crossing a crest tier): `--dur-cinematic`, a single sweep of `--aur-prism` across the emblem + gentle scale settle; reduced-motion → crossfade to new state.
- Provide the emblem at 3 sizes: inline (24px, Today header), medium (Proof card), hero (level-up celebration).

### Asset handoff (to Fable/Higgsfield, later)
- Generate **original** crest textures/backplates only — no recognizable real armor, logos, or referenced characters. The SVG structure is authored in-repo; generated art is optional decorative overlay behind/around the SVG.

## 6. Layout & components (visual language)
- Bottom tab bar in forged-glass over cobalt. 44px+ targets. Thumb zone respected.
- Cards = forged-glass on `--aur-night`, generous radius (`16–20px`), hairline chrome border.
- One primary CTA per screen, high-contrast chrome-on-cobalt.
- Data (weights/reps/timer) in mono, tabular, large enough to read mid-set.
- Empty states use the calm voice + a single next action (never nagging).
